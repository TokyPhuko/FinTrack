# Миграции

Этап 1: схема создаётся автоматически через `Base.metadata.create_all` при старте
(`app/database.py:init_db`).

При переходе на изменения схемы и/или PostgreSQL здесь появятся версионированные
SQL/alembic-миграции. SQLite-файл лежит в `data/fintrack.db` — для полного сброса
тестовых данных удалите его (и перезапустите приложение).
