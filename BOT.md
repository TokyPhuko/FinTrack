# Telegram-бот FinTrack

**Бот:** [@gazebo_bro_bot](https://t.me/gazebo_bro_bot)  
**Токен:** в `.env` → `TELEGRAM_BOT_TOKEN` (не публикуйте).

## Как пользоваться

1. Открой бота → `/start` (аккаунт admin привяжется автоматически, если ещё не привязан).
2. Пиши суммы текстом:
   - `350 кофе` — расход, категория по подсказке
   - `+50000 зарплата` — доход
   - `-120.50 продукты` — расход
   - `перевод 1000 наличные` — перевод между счетами (**не расход**)
   - `снять 500` — карта → наличные (если есть счёт «Наличные»)
3. Команды:
   - `/stats` — доход/расход/баланс за месяц + топ категорий
   - `/last` — 10 последних операций
   - `/undo` — отменить последнюю (баланс вернётся)
   - `/bind пароль` — привязать этот Telegram к аккаунту (если /start не сработал)
   - `/help`

## Категории

Бот ищет категорию по словам (кофе→Кафе, продукт→Продукты, зарплат→Зарплата…).
Если не нашёл — берёт «Прочее». Свои категории создай в вебе (Категории).

## Запуск

Бот стартует вместе с приложением, если задан `TELEGRAM_BOT_TOKEN`:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
# в логе: Run polling for bot @gazebo_bro_bot
```

Без токена — бот молча выключен, всё остальное работает.
