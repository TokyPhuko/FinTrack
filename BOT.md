# Telegram-бот FinTrack

**Бот:** [@gazebo_bro_bot](https://t.me/gazebo_bro_bot)  
**Токен:** в `.env` → `TELEGRAM_BOT_TOKEN` (не публикуйте).

## Регистрация и вход

Логин = **имя пользователя**.

### В боте (сразу после /start)

🆕 **Новый аккаунт:**
```
/register логин пароль
/register toky mypass
```
Сразу создаёт аккаунт (счёт «Карта» = 0, базовые категории) и привязывает Telegram.

🔑 **Войти в существующий:**
```
/bind логин пароль
/bind admin admin
```

Смена аккаунта: `/unbind`, потом `/register` или `/bind`.

### На сайте

- Регистрация: `http://127.0.0.1:8000/register`
- Вход: `http://127.0.0.1:8000/login`

### Сид-аккаунты

| Логин | Пароль | Назначение |
|---|---|---|
| `admin` | `admin` | тестовый админ |
| `test` | `test` | для совместных счетов/пар |

## Как пользоваться

Пиши суммы текстом:
- `350 кофе` — расход
- `+50000 зарплата` — доход
- `перевод 1000 наличные` — **не расход**
- `снять 500` — карта → наличные

Или спроси: `сколько потратил?`, `баланс?` — отвечает Gemini.

## Команды

| Команда | Что делает |
|---|---|
| `/register логин пароль` | новый аккаунт + привязка |
| `/bind логин пароль` | вход |
| `/unbind` | отвязать Telegram |
| `/stats` | доход/расход/баланс за месяц |
| `/last` | 10 последних операций |
| `/undo` | отменить последнюю |
| `/xlsx` | Excel-отчёт в чат |
| `/report` | разбор за неделю (LLM) |
| `/accounts`, `/account add …` | счета |
| `/cats`, `/cat add …`, `/cat limit …` | категории |
| `/budget Название 5000` | бюджет месяца |
| `/check` | чек-ин дня (огонёк 🔥) |
| `/streak` | серия и пара |
| `/pair username` | пригласить в парный забег |
| `/help` | справка |

## Запуск

Бот стартует вместе с приложением, если задан `TELEGRAM_BOT_TOKEN`:

```bash
uvicorn app.main:app --host 127.0.0.1 --port 8000
# в логе: Run polling for bot @gazebo_bro_bot
```
